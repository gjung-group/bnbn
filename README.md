This work presents the calculation of the electronic band structure of twisted bilayer boron nitride (tBN) using a full tight-binding model within a commensurate bilayer boron nitride (cBN) configuration. The code used for this calculation is organized into the following sections:

Moiré Generation: This directory contains the code for constructing the twisted bilayer BN using the genmoire package and includes an example of structural relaxation using LAMMPS.

TB Band Example: This directory includes the code for calculating the band structure of twisted bilayer BN with a commensurate twist angle (t2BN).

Post-Processing: This section contains the post-processing codes used to generate the related figures in our work.

The following citation should be used when referencing this work:

Li, Fengping, et al. "Moiré flat bands and antiferroelectric domains in lattice relaxed twisted bilayer hexagonal boron nitride under perpendicular electric fields." arXiv preprint arXiv:2406.12231 (2024).
