# twist bilayer hexagonal Boron Nitride
This work describes the calculation of the electronic band structure of twisted bilayer Boron Nitride (tBN) using a full tight-binding model, with a commensurate bilayer Boron Nitride (cBN) configuration. The code used for this calculation is divided into two parts:

1:Moiren_generation: This folder contains the code for constructing the twisted bilayer BN using the genmoire package.

2:TB_band_example: This folder contains the code for calculating the band structure of t2BN with a commensurate twist angle (t2BN).

Note that the full band structure calculation dataset used for this paper is available upon request.
